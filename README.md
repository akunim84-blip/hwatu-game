# 🎴 혁게임 — 고스톱 · 맞고 · 섯다

카카오톡 단톡방에 링크를 공유해서 친구들과 실시간으로 즐기는 모바일용 화투 웹게임입니다.

> ⚠️ **게임 안에서만 쓰는 가상 머니(원)입니다. 충전·환전 없음.** 실제 돈, 결제, 현금 정산 기능이 없습니다.

- 섯다 (2~5명), 맞고 (2명), 고스톱 (3명)
- 서버가 셔플·딜·규칙 판정·점수 계산을 모두 처리 (각자 자기 패만 받음 → 치팅 방지)
- 방 코드 / 초대 링크(`?room=코드`), "카톡으로 공유" 버튼, 새로고침해도 자리 복귀
  - 초대 링크로 들어오면 방 코드 입력 없이 이름만 쓰면 바로 그 방에 입장
- 계정: 이름만으로 입장 (처음 쓰는 이름이면 바로 계정 생성). 기기별 긴 랜덤 토큰(localStorage, 서버엔 해시만 저장)으로 같은 기기는 자동 로그인
  - PIN 4자리는 선택: '다른 기기에서도 쓰려면 PIN 설정' (scrypt+salt 해시, 잠금 포함)
  - 이미 있는 이름은 그 기기 토큰이나 PIN이 있어야 입장 — PIN 없는 이름은 '이미 쓰는 이름'으로 거절 (남의 잔액 탈취 불가)
  - 마지막 이름은 로그아웃 후에도 입력칸에 미리 채워짐. 잔액은 방·방문이 바뀌어도 유지
  - Postgres는 시작 시 자동 마이그레이션 (pin_hash NULL 허용, 토큰 last_used_at·인덱스)
  - ✏️ **이름 바꾸기**: 로그인한 기기에서만 (PIN 있는 계정은 지금 PIN 확인). 가입과 같은 이름 규칙, 이미 쓰는 이름 거절, 10분에 한 번. 잔액·PIN·기기 토큰·순위 그대로, 옛 이름은 바로 풀림. Postgres는 계정 행+토큰 행을 한 트랜잭션으로 옮김. 앉아 있는 방·방 목록·순위에 바로 반영
  - **계정 삭제**: 지금 이름을 똑같이 입력 + PIN 있는 계정은 지금 PIN. 판 진행 중엔 거부(판 끝나고 방에서 나간 뒤), 대기방이면 방에서 빼고 삭제. 계정·기기 토큰·순위 삭제(Postgres 트랜잭션), 이 기기의 토큰·마지막 이름도 지움, 다른 기기는 로그아웃 알림. 이름은 다시 쓸 수 있음
- **관리자 페이지 `/admin`** (공개 링크 없음): 환경변수 `ADMIN_KEY`가 있어야 켜짐. 키를 한 번 입력하면 서명된 httpOnly 쿠키(30일)로 기억, 틀린 키는 IP마다 10분에 5번까지. 계정 목록·검색(잔액·PIN 여부·가입·최근 접속·접속 중/방), 계정 삭제(접속 중이면 방에서 빼고 로그아웃 알림), PIN 재설정(잊어버린 사람 복구), 잔액 설정/증감, 이름 변경, 열린 방 목록·방 닫기. 관리 작업은 서버 콘솔에 `[admin]` 로그. 로컬에서는 `.admin-key` 파일(gitignore)을 `scripts/start.sh`가 읽음
- **관리자 비밀번호 바꾸기**: `/admin` 위쪽 '🔑 비밀번호' 버튼(현재 키 + 새 키 2번, 8~200자) 또는 `POST /admin/api/change-key` (`x-admin-req: 1` 헤더, 같은 IP 10분 5번 제한). 새 키는 scrypt 해시로 DB(`hwatu_settings`, 없으면 계정 JSON 파일)에 저장되고 그때부터 환경변수 `ADMIN_KEY`보다 우선합니다. 바꾸면 기존 관리자 로그인은 모두 풀립니다. 터미널에서: `HWATU_NEW_ADMIN_KEY=새키 scripts/change-admin-key.sh https://주소` (현재 키는 `.admin-key`에서 읽고 키를 화면·명령줄에 찍지 않음, 성공하면 `.admin-key`도 새 키로 바꿈 — `KEEP_KEY_FILE=1`이면 그대로 둠)
- **기기 기억 (DEVICE_V2)**: 입장 정보(기기 토큰·이름)는 localStorage + 같은 사이트 쿠키(400일)에 함께 저장 — 한쪽이 지워져도 복구. 입장 버튼을 누르면 기기가 토큰을 먼저 만들어 저장한 뒤 서버에 등록(이름·PIN 확인 통과 후에만)하므로 응답이 늦거나 끊겨도 다음 방문에 자동 입장. 자동 입장은 서버가 "없는 토큰"이라고 할 때만 토큰을 지우고, DB가 느리거나 잠깐 오류면 토큰을 지키고 "다시 시도" 버튼. 저장이 막힌 브라우저면 첫 화면에 안내. 주소(오리진)가 바뀌면 처음 한 번은 다시 입장해야 함 (PIN 없는 이름은 원래 기기에서 PIN을 설정해야 새 주소/기기에서 이어서 쓸 수 있음)
- **🎮 다른 게임 메뉴**: 첫 화면 왼쪽 위 / 대기실·게임 머리줄 맨 앞의 🎮 → 🏠 게임 로비(https://game.itf84.synology.me) · ⚔️ 던전 앤 던전(https://ofo.itf84.synology.me), 같은 탭으로 이동. 판에 앉아 진행 중이면 먼저 확인("나가면 AI가 대신 칩니다" — 연결이 끊기면 기존처럼 자리는 남고 자동으로 침). 주소는 `public/app.js`의 `GAME_LINKS` 한 곳
- **전적 (승·무·패)**: 계정마다 고스톱/맞고/섯다별 + 전체. 이긴 사람 승, 나머지 패, 나가리는 모두 무, 섯다 동점(판돈 나눔)은 이긴 사람들 무. AI·손님은 기록 안 함. 판 도중 나가거나 연결이 끊겨도 자리 주인 계정에 기록. 판이 끝날 때 잔액과 같은 UPDATE로 저장(`hwatu_accounts.stats` JSON 컬럼, 서버 시작 때 자동 추가). 첫 화면 계정 칸 '전적 12승 3무 8패 · 승률 52%'(누르면 게임별 표), 대기실 이름 아래 이 게임 전적, 랭킹 이름 아래, 관리자 목록에 표시. **과거 전적 백필 없음**: 예전 코드는 판 기록을 DB에 저장한 적이 없어서(방·기록은 메모리에만, DB에는 잔액·파산 횟수뿐) 모든 계정 0부터 시작합니다. 서버 시작 때 DB 테이블 목록을 로그에 남깁니다(`[accounts] 테이블: …`).
- **계정 칸 배치**: 이름은 한 줄 전체(말줄임 없음), 그 아래 버튼 줄(좁으면 줄바꿈), 그다음 내 돈·전적·계정 삭제. 대기실·게임 자리의 긴 이름은 글씨를 줄이고 필요하면 줄바꿈
- 게임 화면 위쪽 **나가기**: 판이 아닐 때는 바로 나가고, 판 중에는 **나가기 예약**(다시 누르면 취소, 다른 사람 자리에 '나가기 예약' 표시). 판이 끝나 정산된 뒤 자동으로 첫 화면으로, 자리는 AI가 이어받고 방장은 다음 사람에게, 사람이 없으면 방 닫힘. 연결이 끊기면 예약 취소
- **턴 타이머 10초** (`server.js`의 `TURN_MS`, 환경변수로도 변경): 패 내기·먹을 패 고르기·고/스톱·흔들기·섯다 베팅 모두. 서버가 마감 시각을 정하고(패 돌리기·선 정하기·먹는 연출 시간은 따로 더 줌, 재접속해도 안 늘어남), 자리에 줄어드는 막대 + 내 차례엔 큰 숫자(마지막 3초 빨간색·틱 소리). 시간 초과면 자동 행동(맞는 패 우선·좋은 바닥 패·스톱·흔들기 안 함, 섯다는 체크 아니면 다이) + '시간 초과 — 자동으로 냈어요'. 연결 끊긴 사람도 같은 타이머로 자동 진행
- **채팅** 💬 (대기실·게임·관전): 아래에서 올라오는 채팅창 + 안 읽은 개수, 빠른 채팅('빨리 치세요~', '잘 쳤다!', '아쉽다 ㅠㅠ', '한 판 더?', '나이스!', '감사합니다', 이모지), 보낸 사람 자리 위에 3초 말풍선. 서버: 방 안에만, 100자, 5초에 5개, 꺾쇠(<>) 무력화 + 화면에서 이스케이프, 최근 50개는 들어오거나 재접속하면 받음, 입장/퇴장 안내
- 가상 머니: 처음 1,000,000원, 0원 이하가 되면 '파산! 300,000원으로 다시 시작'. 섯다 기본 판돈 10,000원(5천~10만), 맞고/고스톱 점당 1,000원(500~1만). AI는 조용히 충전
- 저장소: 환경변수 `DATABASE_URL`이 있으면 Postgres(`hwatu_accounts`, `hwatu_tokens` 테이블 자동 생성, 실패 시 로그 남기고 JSON으로 대체), 없으면 `data/accounts.json` (gitignore). 판 정산마다 저장
- 연출 (전부 자체 제작 — 외부 게임의 이미지·음원·캐릭터를 쓰지 않음):
  - 판 시작: 맞고/고스톱 첫 판은 **선 정하기**(각자 한 장씩 뒤집어 가장 높은 달이 선 — 서버가 뽑고 결과만 보여 줌), 다음 판부터는 '지난 판 승자가 선' 안내 → '판 시작' 도장 → 셔플·패 돌리기. 화면을 탭하면 건너뜀
  - 큰 도장 + 합성 외침: 1고·2고…, 스톱, 뻑, 뻑 먹기, 3뻑, 따닥, 쪽, 싹쓸이, 흔들기, 폭탄, 고도리/홍단/청단/초단, 삼광/사광/오광, 광박/피박/고박, 나가리 — 엔진이 실제로 판정한 이벤트만
  - 판 끝: 승리(꽃가루·엽전 + 징·장구 소리)/패배(잔잔하게 처지는 배너)/나가리 배너 → 결과 카드에서 돈이 0원부터 올라감. 결과 카드는 전처럼 눌러야 닫힘
  - 섯다: 내 두 번째 패 **조이기**(위로 밀거나 탭하면 천천히 공개), 판 끝에 상대 패를 차례로 뒤집고 이긴 족보(38광땡 등) 도장
  - 외침 목소리: [MeloTTS](https://github.com/myshell-ai/MeloTTS) 한국어 모델(myshell-ai/MeloTTS-Korean, 코드·가중치 MIT)로 만든 사람 목소리 클립 64개 (`public/voice/<key>.webm|mp3`, 합계 약 0.7MB). 첫 터치 뒤 미리 받아 Web Audio로 재생(🔊 음소거·배경음악 줄이기 적용), 못 받으면 예전 합성음으로 대신. 생성: `scripts/voice/gen_voice.py` + `scripts/voice/clips.json` (시드 고정). **직접 녹음으로 바꾸기:** `public/voice/manifest.json`의 key 이름 그대로 `<key>.mp3`(필수)·`<key>.webm`(선택)을 덮어쓰면 됨
  - 배경음악 🎵: 5음 음계 가야금 느낌의 뜯는 소리 + 장구(덩·쿵·덕)·징 장단을 Web Audio로 실시간 합성 (대기실 곡·게임 곡, 음원 파일 0개). 기본 켜짐이지만 첫 터치 뒤에만 재생, 작은 소리, 도장/효과음이 날 때 잠깐 줄어듦. 🎵 버튼으로 끄기(localStorage `hw_bgm`), 🔊 끄면 전부 무음
- 첫 화면: 진행 중인 방 목록(실시간, 눌러서 참여/관전), 내 돈, 순위 Top 10. 게임 중인 방에 들어가면 관전 후 다음 판부터 AI 자리를 넘겨받음

| `lib/ai.js` | AI 상대 의사결정 (자기 패 + 공개 정보만 사용). 맞고/고스톱: 광·띠·쌍피·족보 완성/막기 우선, 고/스톱 판단, 흔들기·폭탄. 섯다: 족보 강도 기반 베팅/다이 + 약간의 블러핑. 난이도 쉬움/보통 |

## 내 PC에서 실행

1. [Node.js](https://nodejs.org/) (18 이상, LTS 권장) 설치
2. 이 폴더에서 터미널을 열고:
   ```bash
   npm install
   npm start
   ```
3. 브라우저에서 **http://localhost:3300** 접속
4. 같은 와이파이의 휴대폰에서는 `http://<내 PC IP>:3300` 으로 접속 가능

테스트: `npm test` (단위 테스트), `npm run sim` (봇 200판 시뮬레이션)

## Render 배포 방법 (무료)

1. 이 프로젝트를 GitHub 저장소에 올립니다.
2. [Render](https://render.com) 로그인 → **New +** → **Blueprint** 선택 → 저장소 연결
   (`render.yaml` 이 자동으로 인식됩니다: Web Service, Node, Free 플랜,
   빌드 `npm install`, 시작 `npm start`, 헬스체크 `/`)
   - Blueprint 대신 **New + → Web Service** 로 직접 만들어도 됩니다. 이때 Runtime `Node`,
     Build Command `npm install`, Start Command `npm start`, Instance Type `Free` 로 설정하세요.
3. (선택) 관리자 페이지를 쓰려면 Render 서비스 **Environment**에 `ADMIN_KEY`(긴 무작위 문자열)를 추가하세요. 없으면 `/admin`은 꺼져 있습니다.
4. 배포가 끝나면 `https://<서비스이름>.onrender.com` 주소를 카톡방에 공유하면 됩니다.

참고 (무료 플랜):
- 15분 동안 접속이 없으면 서버가 잠들고, 다음 접속 때 깨어나는 데 30초~1분 정도 걸립니다.
- 방 정보는 메모리에만 저장되므로 서버가 재시작되면 방이 사라집니다.
